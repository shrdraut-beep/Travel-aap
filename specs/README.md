# Specifications Index (`/specs`)

This directory contains all feature specifications, technical execution plans, and task breakdowns following the **Spec-Driven Development (SDD)** model.

## Directory Structure
```
specs/
├── 001-spec-kit-setup/
│   ├── spec.md
│   ├── plan.md
│   └── tasks.md
└── [feature-number-name]/
    ├── spec.md
    ├── plan.md
    └── tasks.md
```

## Available Commands
- `/speckit.constitution`: View or update project constitution
- `/speckit.specify`: Draft feature specification
- `/speckit.plan`: Create technical design plan
- `/speckit.tasks`: Breakdown actionable task checklist
- `/speckit.implement`: Execute implementation against tasks
- `/speckit.clarify`: Query ambiguities
- `/speckit.analyze`: Audit spec compliance and drift
