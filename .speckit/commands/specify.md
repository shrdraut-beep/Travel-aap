# Command: /speckit.specify

**Purpose**: Create a functional feature specification (`spec.md`) under `specs/[feature-id]/spec.md`.

**Instructions for AI Agent**:
1. Gather user requirements, target roles, and core intent.
2. Outline user stories, functional requirements, non-functional constraints, and non-goals.
3. Use `.speckit/templates/spec-template.md` as the base.
4. Save file to `specs/[feature-id]/spec.md`.
