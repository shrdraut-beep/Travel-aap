# Command: /speckit.tasks

**Purpose**: Generate a step-by-step checklist of actionable implementation tasks (`tasks.md`).

**Instructions for AI Agent**:
1. Read `specs/[feature-id]/spec.md` and `specs/[feature-id]/plan.md`.
2. Break down implementation into phases with actionable sub-tasks.
3. Include linting and compilation verification steps.
4. Save to `specs/[feature-id]/tasks.md`.
